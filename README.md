# Cardápio Digital

Cardápio digital feito em HTML, CSS e JavaScript, acessado pelo celular por meio de um QR code. Ele já está em funcionamento no restaurante onde foi implantado.

## Como funciona

1. O cliente aponta a câmera do celular para o QR code.
2. O cardápio abre direto no navegador, sem precisar instalar nada.
3. O cliente navega pelos itens e vê as opções disponíveis.
